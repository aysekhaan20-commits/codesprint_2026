# CodeSprint 2026 — Technical Team Build Challenge

A responsive landing page concept for a fictional student technology event.

## Features
- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu
- Event introduction, tracks, illustrative schedule and FAQ
- Front-end demo registration form with browser validation
- Semantic HTML and accessible status message

## Built with
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
1. Extract this ZIP file.
2. Open the `codesprint_2026` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Test the navigation and demo registration form.

## Important note
CodeSprint 2026 is a fictional event concept created for a recruitment build challenge. The registration form is front-end only: it does not send, collect, or store personal information.
