# CodeSprint 2026 – Technology Event Landing Page

## About the Project

CodeSprint 2026 is a responsive landing page designed for a fictional student technology event. The website aims to encourage students to explore technology, collaborate with other developers, and develop creative ideas.

This project was developed as part of the CodeForce Technical Team recruitment challenge at MIT ADT University.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layout and responsive design
- JavaScript – Interactive elements and form validation

## Features

- Modern and responsive user interface
- Navigation menu for desktop and mobile devices
- Event introduction and information
- Three technology tracks:
  - Web & Product
  - Data & AI
  - Open Innovation
- Illustrative event schedule
- Interactive FAQ section
- Demo registration form with input validation
- Mobile-friendly layout

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the website and test its interactive features.

You can also use the Live Server extension in VS Code.

## Registration Form

The registration form is a front-end demonstration. It validates user input and displays a confirmation message. It does not send or store personal information.
